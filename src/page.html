API Key 策略

可观测性

SQLite 只保存路由元数据，不保存 Prompt、响应正文、完整 API Key 或 OAuth Token。写库异步执行，不应阻塞模型请求。v0.6 起，未配置 KCR Policy 的 API Key 请求不进入内存、SQLite 或 KCR routing log。

路由记录

只记录已配置 KCR Policy 的请求；未配置 Policy 的 API Key 直接忽略，不显示也不存储。列表默认保持紧凑，点击任意行展开候选尝试和选择原因。

新建策略

同一个下游 API Key 只能存在一个 Policy。模型 Rule 由精确匹配优先、glob 次之、* 最后。
